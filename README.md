# 📊 Sales Performance, Budget & Variance Analysis Dashboard

## 📌 Project Overview

This project is an interactive **Power BI dashboard** developed to analyze sales performance, customer/location performance, product performance, salesperson performance, year-over-year growth, and budget variance.

The dashboard provides interactive visualizations and KPI cards that help users understand sales trends and compare actual sales with budget values.

---

## 🎯 Objectives

The main objectives of this Power BI project are:

- Analyze overall sales performance
- Track total sales, orders, and quantity
- Analyze sales performance by product
- Analyze sales by location, state, and county
- Analyze salesperson performance
- Compare sales performance across different years
- Analyze Year-over-Year (YoY) growth
- Compare actual sales with budget
- Analyze budget variance and budget variance percentage
- Provide detailed data tables for further analysis

---

## 📊 Dashboard Pages

### 3. Product Performance Analysis

### 5. Salesperson Performance Analysis

## 🧮 Key Measures

The dashboard uses DAX measures for calculating important business metrics such as:

- Total Sales
- Total Orders
- Total Quantity
- Average Order Value
- Average Selling Price
- Sales YTD
- Sales LY
- YoY Growth %
- YoY Growth Amount
- Total Budget
- Monthly Budget
- Budget Variance
- Budget Variance %

These measures are used across the dashboard to create interactive KPIs and visualizations.
